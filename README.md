# Homebrew tap

Homebrew casks for apps by Jordan Campbell.

```bash
brew install --cask jordancampbelldesign/tap/umbra
```

- **umbra:** a free menu bar app to control the brightness, contrast, volume, input, and power of every monitor. [Source](https://github.com/JordanCampbellDesign/Umbra)

Umbra updates itself. `brew upgrade --cask umbra` also works.
